# Linux System Administrator Portfolio

Personal portfolio website for an aspiring Linux System Administrator pursuing RHCSA (EX200) and AWS CLF-C02 certifications.

## Stack

- Plain HTML5 + CSS3 + vanilla JavaScript (no frameworks)
- Google Fonts: Inter + JetBrains Mono
- Zero build step — open index.html directly or deploy as-is

## Deploying to GitHub Pages

1. Push this folder to a GitHub repo (e.g. `username.github.io` or any repo)
2. Go to **Settings > Pages**
3. Set source to `main` branch, root folder
4. Your site will be live at `https://username.github.io`

## Deploying to Netlify

1. Drag and drop this folder into [netlify.com/drop](https://app.netlify.com/drop)
2. Done — instant live URL

## Customising

- Replace all instances of `[Your Name]` with your actual name
- Replace `your.email@example.com` with your real email
- Update the GitHub repo links in each project card once repos are created
- Swap `favicon.png` with your own if desired
